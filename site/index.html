Pixel-art effects in Rust

Make auras hug your sprites and trails follow their motion. Play the same effects live or export them to sprite sheets and GIFs.

Explore effects Get started

Where it runs

Use the Rust crates or JavaScript bindings from source. The same engine paints the pixels for every host.

Export composite, colour and light PNGs with Aseprite-style JSON, or write a looping GIF.

cargo run -p pixfx-export --example sprite_sheet -- feedback/power-up --out out
cargo run -p pixfx-export --example gif -- feedback/power-up --scale 4 --out out

Scripts · Sprite sheet format

Effects are painted on worker threads and drawn on a Canvas 2D context, upscaled by a whole number with no smoothing, among your own drawing.

import { createPixfx, loadPixfx } from "pixfx-canvas2d";

await loadPixfx();
const pixfx = createPixfx(canvas.getContext("2d"), { scale: 4 });
pixfx.play("impacts/parry", 64, 112, { seed: 3 });
// each frame: pixfx.update(dt), then pixfx.draw()

Canvas 2D shell reference

A scene plugin. Effects show up as ordinary Phaser images, a back pair and a front pair, so sprites can stand inside an effect.

import { PixfxPlugin, loadPixfx } from "pixfx-phaser";

await loadPixfx();
// plugins: { scene: [{ key: "pixfx", plugin: PixfxPlugin, mapping: "pixfx" }] }
const trail = this.pixfx.play("projectiles/trail", 150, 170);
trail.follow(player);

Phaser plugin reference

Attach effects to Pixi sprites. Pixi’s ticker drives playback and workers paint the frames.

import { createPixfx, loadPixfx } from "pixfx-pixi";

await loadPixfx();
const pixfx = createPixfx(app);
pixfx.play("projectiles/trail", 0, 0).follow(player);

Pixi 8 shell reference

Drive an effect yourself and read its pixels: RGBA bytes, or the colour and light layers separately.

import init, { Fx } from "./pkg/pixfx_wasm.js";

await init();
const fx = new Fx("impacts/parry", { seed: 1 });
fx.update(1 / 60);
fx.draw("both");
ctx.putImageData(new ImageData(fx.rgba(), fx.width(), fx.height()), 0, 0);

JS engine reference

Render frames in Rust, hash them, composite them or export them.

use std::path::Path;
use pixfx_core::{Options, render_frames};

let fx = pixfx_effects::effect("feedback/power-up").ok_or("not registered")?;
let rendered = render_frames(fx, &Options::default(), 0);
pixfx_export::write_gif(Path::new("power-up.gif"), &rendered, 4)?;

Rust API reference

Paint effects inside a gpui window, light blended additively on the GPU with nearest sampling.

use pixfx_core::{Layer, Options};
use pixfx_gpui::FxScene;

let mut fx = FxScene::default();
let parry = pixfx_effects::effect("impacts/parry").ok_or("missing effect")?;
let spark = fx.play(parry, Options::default())?;

fx.tick(dt)?;
// Inside gpui's paint callback
fx.paint(spark, Layer::Both, origin, 4, window)?;
fx.end_frame(window)?;

gpui reference

Try it in a minute

  1. Clone the repository. rust-toolchain.toml pins the nightly and the wasm target, so rustup fetches them on first build.

  2. Render the power-up to a GIF:

    cargo run -p pixfx-export --example gif -- feedback/power-up --out out

  3. Or play it in the browser through the Canvas 2D demo:

    cd packages/pixfx-web && bun install && bun run build:wasm
cd ../pixfx-canvas2d && bun install && bunx vite demo
