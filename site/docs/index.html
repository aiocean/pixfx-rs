pixfx documentation

pixfx is a set of pixel-art effects and the Rust engine that draws them. An effect is written once and produces the same pixels natively and in WebAssembly.

What you can do with it

  • Render. Run an effect natively and write sprite sheets (composite, colour and light PNGs plus a beanfx-layout JSON), or a looping GIF. See Scripts.
  • Play live. Run the same effect in a browser through a Canvas 2D renderer that owns its loop, through plain JS bindings, inside a Phaser 4 scene, or inside a gpui window.

The effects are ports of pixelfx (JavaScript). The ported effects match pixelfx exactly: fire/candle, fire/campfire and fire/brazier render with 0 differing pixels against pixelfx commit 044e12a.
