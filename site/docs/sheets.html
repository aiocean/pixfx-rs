Sprite sheet format

What the sprite_sheet script writes: three PNGs laid out on one grid, and an Aseprite-style JSON atlas with pixfx layer metadata.

Layout

Every frame is one cell of the same size, the effect's canvas (meta.size, or the size its options give, as outline's w and h, plus twice the margin; the scripts use margin 0). Cells go left to right, at most 8 per row, then down.

EffectCellFramesGridSheet size
projectiles/trail160×16088×11280×160
feedback/power-up160×1441818×231280×3312

A loop has round(duration × fps) frames; frame i is the effect after i steps of 1/fps, so the last frame leads back into the first. A one-shot has one more frame, its last moment.

The three images

  • <name>.png (RGBA): colour with light added, over transparency, as composite makes it. Draw it normally when your engine cannot blend additively. It reads correctly over dark backgrounds.
  • <name>_color.png (RGBA, straight alpha): the colour layer only. Draw it normally.
  • <name>_light.png (RGB): the light layer only. Draw it over the colour with additive blending (src + dst). Black adds nothing.

Drawing _color then _light additively gives the effect exactly as the live renderers show it, lighting whatever is under it.

JSON

The frames array and standard meta fields describe the composite atlas for tools such as Phaser's load.aseprite. All layers share those frame rectangles. meta.pixfx describes how to play the effect and draw its layers. This is an abridged export for impacts/parry.

{
  "frames": [
    {
      "filename": "impacts_parry 0",
      "frame": { "x": 0, "y": 0, "w": 200, "h": 112 },
      "rotated": false,
      "trimmed": false,
      "spriteSourceSize": { "x": 0, "y": 0, "w": 200, "h": 112 },
      "sourceSize": { "w": 200, "h": 112 },
      "duration": 33
    }
    // ... one entry per frame
  ],
  "meta": {
    "app": "pixfx",
    "version": "2",
    "image": "impacts_parry.png",
    "format": "RGBA8888",
    "size": { "w": 1600, "h": 448 },
    "scale": "1",
    "frameTags": [{ "name": "impacts_parry", "from": 0, "to": 30, "direction": "forward" }],
    "pixfx": {
      "pivot": [100, 96],
      "fps": 30,
      "loop": false,
      "layers": [
        { "image": "impacts_parry_color.png", "blend": "normal" },
        { "image": "impacts_parry_light.png", "blend": "add" }
      ]
    }
  }
}

Fields

FieldMeaning
frames[].durationMilliseconds per frame, round(1000 / fps).
frames[].frameThe cell on the sheet. Cells are never trimmed or rotated.
meta.frameTagsOne tag spanning every frame, named after the effect.
meta.pixfx.pivotThe effect's origin within a cell, y down from the cell's top-left: the origin on its canvas plus the margin (meta.origin + margin unless its options size the canvas). Place this point where the effect should stand.
meta.pixfx.fpsExact frames per second. Use this when the rounded millisecond durations would introduce drift.
meta.pixfx.loopWhether playback repeats after the last frame.
meta.pixfx.layersDraw these layers in array order using the shared frame rectangles. Image paths are relative to the JSON. Normal means source-over, and add means additive at full strength.
